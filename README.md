A faster drop-in CSV reader, exactly compatible with csv-reader 1.0.0: a single-pass slice-based scanner that produces byte-identical answers on every input — including broken quoting, stray carriage returns, CRLF mixes and unterminated quotes — while parsing several times faster than the reference implementation. Entered in the make.fun bounty "Read broken CSV files faster, 21 November 2026".

## Run it

```sh
MAKEFUN_INPUT_DIR=/input MAKEFUN_OUTPUT_DIR=/output node main.ts
```
